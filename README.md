## ✦ Overview

This repository houses the personal portfolio of **Adnan A Laskar**—a STEM student at **Dr. B.R. Ambedkar School of Specialised Excellence (Kalkaji)**, Frontend Developer, and UI/UX Designer.

The site is built to bridge creative visual identity with structured, type-safe frontend engineering, highlighting hackathon achievements, visual design concepts, and interactive web experiments.

### Key Highlights
* **Maroon & Cream Design System:** High-contrast, warm typographical hierarchy coupled with an engineered background grid pattern.
* **Modular TypeScript Engine:** Type-safe dynamic rendering (`src/main.ts`) for project entries, dynamic filtering, and modal states.
* **Interactive Lightbox Modal:** Dynamic project inspector for detailed breakdowns and visual design studies.
* **Hackatime-Compatible Activity Logging:** Custom background heartbeat integration syncing real coding time to Hack Club's platform.
